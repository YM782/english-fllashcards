# 美式英语发音学习卡片

单文件静态网页，提供搜索、分类、收藏、掌握标记及自定义词卡。打开 [index.html](index.html) 查看实现。

## 本机使用

在此目录执行 `python -m http.server 8685 --bind 127.0.0.1`，再打开 http://127.0.0.1:8685/ 。端口可替换为任意空闲端口。网页不需要构建步骤或账号服务。

## 发音与数据

- 真人录音按需从 Wikimedia Commons 查找，并显示作者和许可；部分单词没有录音或网络请求会失败。
- 剑桥词典按钮跳转至外部词典，需联网。
- 例句和“备用合成音”使用设备的文字转语音能力，音色取决于浏览器和已安装语音包。
- 收藏、掌握状态和自定义词卡保存在当前浏览器的 localStorage；不会跨设备同步。清除网站数据会失去记录。
- 存储格式损坏时跳过非法记录，存储写入失败时显示提示。原有存储键保持不变。

## 维护

内置词卡位于 `index.html` 的 `seed` 数组；字段包括 `w`、`ipa`、`zh`、`cat`、`ex` 和 `tr`。发音、释义与例句应逐项依据词典复核；本次界面修正不代表全部词条已完成语言学校对。
